This is the folder containing the code related to the evaluations of the models.

1. TDCalculations.ipynb : Code to calculate NPMI and TD of BBC News Dataset using LDA, NMI, Bertopic Topic Modeling

2. test.ipynb : Code to calculate NPMI and TD of Mistral topic modeling on 20NewsGroups data

3. BBC Mistral: Code to calculate NPMI and TD of mistral topic modeling on BBC News data

4. AutomaticMetricsCode.ipynb: Code to calculate automatic metrics on generated summaries

5. FactCheckingCode.ipynb: Code to do hallucination check on generated news articles.
